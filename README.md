# Códigos de serviço (LC 116) com NBS correspondente

Tabela aberta dos códigos de serviço da NFS-e Nacional, com os NBS correspondentes, indicador de operação e classificação tributária (IBS/CBS).

- `codigos-servico-nbs.csv`: uma linha por código × NBS (UTF-8, separador vírgula).
- Fontes oficiais: Anexo B da NFS-e Nacional (LISTA.SERV.NAC. e LISTA.NBS_v2.0, v1.01, 22/01/2026) e Anexo VIII (Correlação Item × NBS × IndOp × cClassTrib, IBS/CBS V1.00.00).
- Dado oficial sem alteração, sem interpretação. Confira sempre a versão vigente do Ambiente Nacional.

Consulta com busca: https://sendnf.com/codigos-de-servico/

Para emitir a NFS-e com esses códigos: [como emitir NFS-e no SendNF](https://sendnf.com/nfse/). Para integrar por código: [API do SendNF](https://sendnf.com/desenvolvedores/).
